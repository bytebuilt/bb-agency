# ByteBuilt website

A responsive, single-page agency website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content, metadata and structured data
- `style.css` — responsive visual system and animations
- `script.js` — mobile navigation, scroll effects and contact form behaviour
- `favicon.svg` / `apple-touch-icon.svg` — temporary vector brand mark

## Preview locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy
Upload the files to your hosting provider or place them in the root of a GitHub repository connected to your preferred static hosting service.

## Before launch
1. Replace the temporary cube logo with the exact approved ByteBuilt logo when available.
2. Confirm all service descriptions, package prices, payment methods, and response-time claims.
3. The contact form currently opens the visitor's email application (`mailto:`). For a form that submits without requiring an email app, connect Formspree, EmailJS, or a custom backend.
4. Add real video examples when ready. The current vertical panels are clearly labelled concept previews, not client work.
5. Confirm canonical domain and social profile URLs before publishing.
6. SVG is supplied as the Apple touch icon source; if a platform requires PNG, export a 180×180 PNG from it.

## Notes
The page uses Google Fonts, so the font files are fetched from Google Fonts. System fallbacks remain available if the request fails.
